# Basketball Attendance Dashboard (POC)

Este proyecto es un **Proof of Concept (POC)** para gestionar y visualizar la asistencia de jugadores de baloncesto en eventos tipo entrenamiento.  
El objetivo principal es contar con un tablero profesional que muestre la asistencia semanal, notas específicas de cada evento y resalte visualmente la información con colores.

---

## 🚀 Características

- **Visualización semanal**: cada jugador aparece en una sola fila con sus asistencias distribuidas por semana.
- **Notas específicas**: las ausencias incluyen el motivo (lesión, viaje, trabajo, etc.).
- **Resaltado visual**: celdas en verde para "Presente" y en rojo para "Ausente" o con nota.
- **Datos de prueba**: se incluyen registros completos para el mes de abril (5 semanas, 14 jugadores).
- **Integración con MudBlazor**: uso de componentes modernos para tablas, estilos y chips.
- **Control de versiones con Git**: repositorio inicializado con `.gitignore` para proyectos .NET.
